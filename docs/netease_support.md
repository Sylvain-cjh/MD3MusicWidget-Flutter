# 网易云歌词与公开歌单

本次开发构建沿用 0.12.6.1，未重新打包。

## 使用

- 歌词：设置 → 歌词 → 歌词来源 → 网易云音乐 · beta。可以配合 QQ 音乐等系统播放器使用，不要求网易云客户端运行。
- 歌单：设置 → 播放 → 开启下一首预告 → 预告歌单来源 → 网易云音乐。连接公开歌单的数字 ID 或 `https://music.163.com/#/playlist?id=…` 链接。
- QQ、网易云和本地歌单通过同一个下拉框选择，只显示当前来源的连接选项；切换不删除其他来源的链接。
- 预告仍只在设定的临近结束窗口出现，沿用现有进入、退出和空间释放动画；不是播放器实际队列。

## 边界

仅使用无需登录的公开元数据端点。不读取 Cookie、密码或客户端私有数据库，不下载音频。歌词以歌名、歌手和时长匹配；有歧义、无歌词或接口失败时回退到 LRCLIB，并显示实际来源图标。

歌单最多处理 2000 首；私有、受限、格式不完整或只返回部分曲目的歌单会报错，不从残缺列表猜测下一首。重复曲目无法唯一定位时不预告。随机播放、单曲循环和临时插播不保证预测准确。

网易云图标来自本机已安装客户端的原始应用图标，仅用于来源标识，不代表官方合作。

## 已验证

2026-10-07 的本机公开接口测试：同步歌词获取通过（公开测试曲目“董小姐 / 宋冬野”），缓存复用通过；公开榜单 3778678 的 200 首曲目解析和下一首匹配通过。第三方端点可能变化，本接入仍为实验性功能。

自动化测试覆盖歌词匹配、回退、缓存、并发请求、设置保存，及歌单链接校验、权限失败、残缺列表拒绝、唯一曲目定位和设置下拉选择。

## 性能采集

`tooling/process_performance_sample.ps1` 只读采集指定进程，不操作鼠标键盘、不结束进程、不安装软件。原始 CSV 和汇总 JSON 保存在 `temp/performance/`。

- CPU：进程 CPU 时间增量 / 实际采样间隔 / 逻辑处理器数。
- GPU：通过 PDH 的英文 GPU Engine 计数器采样，按 PID 与适配器／引擎归组，显示该进程最繁忙引擎的占用，不累加不同引擎，不冒充整机 GPU 或界面 FPS。
- 内存：Private Bytes（私有提交量）与 Working Set（驻留物理内存），分别记录均值和峰值。
- 默认 30 次、每 500ms 一次。第一条 CPU 无历史增量，统计时跳过；计数器不可用时记录原因和空值。

短测只能反映当时配置，不能用于宣称优化百分比。需要在相同歌曲、窗口大小、特效、驱动、电源模式及后台负载下比较，且多个进程的 Working Set 不宜直接相加作为独占内存。

桌面自动操作已经因用户按 Escape 停止。完整实机交互与性能矩阵由用户手动打开新构建并选择测试场景后进行；自动化测试和公开接口测试不等同于全部实机验证。

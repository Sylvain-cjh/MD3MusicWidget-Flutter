# 外观、动画与缓存

这里收纳首页没有展开的设置细节。默认字体为内置 MiSans VF，实际效果会随歌曲封面、主题、窗口尺寸和所选字体变化。

## 布局与窗口

- 设置分为窗口、外观、播放、歌词、字体五个板块，不可用的选项按条件隐藏。
- 支持横版、竖版，尺寸可选择 82%、100%、122%，也可使用锁定宽高比的自由缩放。
- 100% 基准采用紧凑尺寸：横版宽 432、竖版宽 306 逻辑像素。高度随频谱、歌词和下一首预告是否显示而变化，其他档位与面板一起缩放。
- 竖版没有横版右侧的附加封面；横竖切换时，背景以模糊渐变衔接，其余组件连续变换，中途反向从当前进度接续。
- 自由缩放忽略一物理像素以内的取整误差回写；临时零尺寸和过期布局回调不会改写选定比例。
- 可隐藏上一首、播放／暂停、下一首三个控件，只保留音乐展示。开启鼠标穿透后，点击托盘图标可恢复交互，完全退出使用托盘菜单。

## 主题、背景与封面

- 根据封面取色，支持流光背景、左右光效、毛玻璃与 3D 悬浮封面。白色占比较高时跳过近白取色点，没有可靠颜色时使用稳定的中性配色。
- 深色模式下关闭流光后，才能启用 OLED 模式。
- 横版右侧渐变封面自适应铺满，可分别调整压暗、渐隐长度与柔化程度，X／Y 渐隐可联动或独立调节，并支持实时预览、重置。
- 3D 分层是可选功能，模型准备完成前保留原图，完成后连续衔接。缺少模型、没有兼容核显或识别不可靠时保留普通封面；不以 CPU 或独显推理回退。详见 [cover-layers 说明](layer_models.md)。
- 背景在图片解码完成后才开始混合，快速切歌会继承当前画面。模糊结果按封面、尺寸、模式和 DPI 复用；暂时缺图保留有效旧图，持续缺失时先淡出再释放。
- 歌名、歌手与播放时间按背景明暗自动选择黑色或白色，不增加灰色文字底框。取色使用低分辨率平均色调与当前遮罩估算，不持续读回 GPU 像素；局部明暗反差很大的封面仍需检查可读性。

## 动画与数值调节

- 歌名、歌手和歌词有多种切换效果，进入、退出可以联动，也可以分别设置。
- 主封面的柔和滑移会根据上一首／下一首调整方向，旧封面随新封面位置渐隐；播放按钮具有轻量分层 3D 点按反馈。
- 暂停时组件压暗，播放键保持醒目，恢复后连续回到正常亮度。
- 数值滑块采用 MD3 主题色、细圆角轨道和状态层，不叠加玻璃或亚克力纹理。手柄按速度与方向适度形变，数值和稳定点击区域始终跟手。
- 双击滑块上方数值可手动输入，回车确认、Esc 取消，按百分比、字重、MiB 等显示单位输入。重置按钮预留空间，出现时不挤动后面的选项。
- 顶部板块导航使用独立液态滑块；系统启用减少动画时保留正常操作，并采用对应的简化效果。
- 设置悬停只更新高亮，不切换板块、不重播选项入场动画，也不写入原生窗口尺寸；列表边缘保留圆角与滚动渐隐。

## 频谱、进度与监视器

- 频谱支持均衡柱状、镜像频谱和平滑波形，粗细连续调节。柱数可随粗细自动变化，也可手动设为 1–128 根；少量柱不会被简单拉伸铺满。
- 暂停或没有歌曲时保留频谱面板，不用随机波动代替真实音频。
- 进度条可以在后方显示已播放／总时长。播放器没有提供时间线时，不根据软件启动时刻猜测进度。
- FPS、CPU、GPU、内存可以分别开关。只显示一项或两项时附真实趋势波形，三项或四项采用紧凑摘要；竖版内存只显示已用量。
- FPS 针对选择的游戏／程序，其余指标反映整机情况；这不是挂件自己的运行监视器。各采集方式、权限与限制见 [性能监视器说明](performance_monitor.md)。

## 歌词与字体

- 歌词可以跟随主题字体，也可独立选择字体、字重和字号。字体字重用连续滑块调节，数值支持输入和重置。
- 逐字高亮与烟雾消散需要真实字／词级时间轴，不从普通整句 LRC 平均分配演唱时长。开启消散后不叠加扫字效果，暂停和进度调整按当前时间处理。
- 歌词微调以秒显示，范围 -5.000～+5.000 秒，手动精度 0.001 秒；正值提前、负值延后。只影响歌词，不改变播放进度、音频或预告；旧毫秒设置保持兼容。
- “没有歌词时自动隐藏”会收回可见外框，但不改变向系统申请的窗口大小；加载和重试时不会提前隐藏。
- MiSans VF 已内置，无需另装。用户选择的自定义字体仍优先，Windows 字体补足未覆盖字符；字重映射到字体的实际可变轴。
- 文字保留 Flutter 原生绘制，并按布局／DPI 记录像素基线偏移，不先转成低分辨率图片再放大。这不等于强制开启 RGB／ClearType 次像素抗锯齿。

歌词格式、来源、双行处理与逐字限制见 [逐字歌词说明](word_lyrics.md)。

## 缓存与查询

在 **外观 → 缓存与存储** 中分别调节歌词与背景的磁盘容量，每档 1 MiB。

| 缓存 | 默认 | 范围 |
| --- | ---: | ---: |
| 歌词 | 16 MiB | 0–256 MiB |
| 背景 | 128 MiB | 0–1024 MiB |

- 缓存默认保存在 `%LOCALAPPDATA%\MD3MusicWidget\cache-v1`，退出和关机后仍可使用。超限时先清理较少使用的内容，拖动停止后保存和整理，避免每次微调都清理磁盘。
- 调到 0 表示不保留对应磁盘缓存，会清理该类缓存，但不移除当前正在显示的内容。清理按钮不会删除个人 LRC、歌单或其他文件。
- 可以更换缓存位置，使用专用子目录并保留原位置副本；自定义磁盘暂时不可用时回到默认位置，不阻止启动。
- 背景磁盘缓存保存源图和色调，不是最终 GPU 模糊纹理；重启后仍需解码与绘制，磁盘容量也不是运行内存上限。缓存不显示命中提示。
- 有效歌词优先读缓存。歌名、歌手、时长和版本信息共同参与匹配；强制刷新会绕过持久缓存，不用明显不同的歌曲版本凑数。
- 暂时性失败或支持重试的未匹配结果最多尝试三次，间隔约 0.5 秒、1.5 秒；QQ／网易云未命中后继续尝试可用后备来源，各阶段有独立时限。
- 支持的服务限流会按冷却与退避策略，在最长约五分钟的窗口内有限重连，不通过切歌、连续刷新绕过冷却。切歌后旧歌曲的请求失效。
- 已有逐行缓存先直接显示，再在后台补齐真实逐字数据，不反复插入加载提示。较晚到达的逐行结果不覆盖已保存的逐字歌词，补查失败也不会永久锁死。
- 歌词查询直连，不读取系统 HTTP 代理，也不更改系统代理；VPN、虚拟网卡和操作系统路由仍由系统控制。公开歌单客户端的联网策略与歌词客户端独立。

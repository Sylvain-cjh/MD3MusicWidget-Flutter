# cover-layers 分层模型安装与使用

1.0.0 提供三个主要套件：有模型应用版、无模型应用版，以及独立的 cover-layers 模型包。有模型版开箱可用；无模型版仍显示普通封面和 3D 卡片，不因为缺少模型而影响音乐、歌词、频谱等功能。cover-layers 是发行套件名称；内部预训练 ONNX 文件保留兼容文件名与来源信息。

## 给无模型版补装

先退出挂件。独立模型包中的安装程序会要求选择安装有 1.0.0 主程序的文件夹，不能安装到与主程序无关的位置。对于免安装版，也可以解压模型 Portable ZIP，把其中的 cover_layers_gpu.dll 和 runtime 文件夹合并到主程序 EXE 所在目录，再重新打开挂件。

最终结构必须是：

```text
主程序文件夹/
  music_widget_flutter.exe
  cover_layers_gpu.dll
  runtime/
    cover_gpu/
      模型、GPU 依赖和许可文件
```

只适配本次 1.0.0 x64 发行，不在未知旧版本中强行加载。不要只复制 ONNX，所需 DirectML、ONNX Runtime 和后端 DLL 都必须保留。

无模型版安装程序会在用户选定的主程序安装目录中移除旧的可选分层组件，以确保该版本确实不携带模型；用户字体、设置、歌词缓存和本地文件不在移除范围内。之后仍可用独立模型包补装。

## 使用边界

在设置中开启“3D 悬浮封面”和“封面分层视差 beta”。模型只在准备新封面时运行，不逐帧推理；分层完成前保留原图并连续衔接。有兼容核显时使用核显，缺少兼容核显、模型不可用或识别不可靠时保留普通封面，不偷偷回退到 CPU 或独显推理。

这是主体蒙版与景深视差，不是完整 3D 网格重建；动漫、复杂背景、文字及多主体仍可能识别错误。随附第三方模型、DirectML、ONNX Runtime 的完整许可和来源必须保留。

## 源码与签名

程序源码包和独立模型后端源码包不包含个人训练图片、私人标注、Python 训练环境或实验检查点。源码中的 GPU 后端使用现有预训练模型，非本轮未通过质量门槛的新训练权重。

无模型应用源码默认不部署可选分层运行文件；有模型源码默认部署。复用旧构建目录时可显式设置 CMake 的 MD3_BUNDLE_COVER_MODELS=OFF/ON。

可执行文件沿用自签名证书，Windows 默认不信任该证书；不会自动安装根证书。所有套件不附带发行哈希清单。

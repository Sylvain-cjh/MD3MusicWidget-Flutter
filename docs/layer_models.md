# cover-layers 分层模型安装与使用

1.3.0 同时提供有模型和无模型两个应用版本。有模型版带上次已经发布的正式权重和 GPU 依赖；模型本次没有变化，不单独发行 cover-layers。不装模型仍可显示普通封面和 3D 卡片，不影响音乐、歌词与频谱。

## 安装或复用已有模型

想继续使用模型，退出挂件后直接安装或解压 1.3.0 有模型版。选用无模型安装程序覆盖旧目录时，它会移除可选分层组件，不会清理设置、字体和缓存。也可从已有的 1.2.1 正式模型目录或 `cover-layers-Portable-1.2.1.zip` 中，将 `cover_layers_gpu.dll` 和 `runtime/cover_gpu/` 一起复制到主程序旁；请保留许可。旧模型安装器会检查版本，不要用它对 1.3.0 安装。

最终结构必须是：

```text
主程序文件夹/
  music_widget_flutter.exe
  cover_layers_gpu.dll
  runtime/
    cover_gpu/
      模型、GPU 依赖和许可文件
```

不要只复制 ONNX，所需 DirectML、ONNX Runtime 和后端 DLL 都必须保留。不要从本地实验版本复制试用模型或开发 GPU 后端。

## 使用边界

在设置中开启“3D 悬浮封面”和“封面分层视差 beta”。模型只在准备新封面时运行，不逐帧推理；分层完成前保留原图并连续衔接。有兼容核显时使用核显，缺少兼容核显、模型不可用或识别不可靠时保留普通封面，不偷偷回退到 CPU 或独显推理。

这是主体蒙版与景深视差，不是完整 3D 网格重建；动漫、复杂背景、文字及多主体仍可能识别错误。随附第三方模型、DirectML、ONNX Runtime 的完整许可和来源必须保留。

## 源码与签名

程序源码包和独立模型后端源码包不包含个人训练图片、私人标注、Python 训练环境或实验检查点。源码中的 GPU 后端使用现有预训练模型，非本轮未通过质量门槛的新训练权重。

无模型版源码默认不部署分层运行文件，有模型版源码默认部署。复用旧构建目录时可显式设置 CMake 的 MD3_BUNDLE_COVER_MODELS=OFF/ON。

可执行文件沿用自签名证书，Windows 默认不信任该证书；不会自动安装根证书。所有套件不附带发行哈希清单。

# MD3 Music Widget 更新日志

## 0.9.19（相比 0.9.18）

### 媒体通信与扩展能力

- 新增统一媒体提供者接口，将界面状态与 MusicFetcher 实现解耦，为后续接入其他音乐平台保留稳定扩展点。
- 新增版本化本机 TCP 推送协议，媒体状态、心跳与频谱无需由 Flutter 持续发起高频 HTTP 请求。
- 保留原有 HTTP 接口作为封面、播放控制和连接异常时的兼容回退，升级过程不会破坏现有功能。
- 新增媒体能力位，不支持的进度、频谱或播放控制会在播放器与设置中自动隐藏。

### MusicFetcher 性能与稳定性

- 媒体状态改为优先响应 Windows SMTC 事件，播放中、暂停和无媒体状态采用不同的低频校准周期。
- 频谱仅在界面启用时采集并推送，关闭频谱后停止对应高频工作。
- 新增目标媒体应用会话识别；无法可靠匹配时安全回退到系统回环，避免频谱面板无数据。
- 长连接包含心跳、帧长度校验、断线清理和有界队列，防止慢连接造成内存持续增长。

### 发布资源

- 启用新的清新绿紫撞色 Material 3 均衡器图标，并同步更新应用、托盘和安装程序图标。
- GitHub 源码包现在包含完整的 MusicFetcher 长连接实现，并统一移除发布源码中的代码注释。

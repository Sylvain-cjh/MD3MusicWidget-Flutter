# MD3 Music Widget

<p align="center"><img src="assets/logo.png" width="160" alt="MD3 Music Widget 图标"></p>

一款适合放在桌面或直播画面里的 Windows 音乐组件。它把正在播放的歌曲、封面、进度、歌词和真实音频频谱放进一块可自定义的 Material 3 卡片；不需要绑定音乐平台账号。

[查看从 0.10.0 起的更新记录](CHANGELOG.md)

## ✨ 能做什么

- **现在播放**：显示歌名、歌手、封面、播放状态和连续更新的进度；可选隐藏上一首、播放/暂停、下一首三个控制按钮，保留纯展示模式。
- **横竖布局**：横版和竖版热切换，提供小、标准、大及锁定比例的自由缩放。窗口和内容使用连续动画，竖版不显示横版的附加封面。
- **封面驱动的视觉**：动态取色、左右光效、流光背景、毛玻璃、OLED 深色背景和 3D 封面交互。常见封面会命中容量受控的缓存。
- **真实音乐频谱**：从 Windows 音频输出采集信号，可选柱状、镜像或平滑波形；暂停或无歌时保留低亮度面板，不用随机动画冒充音乐。
- **歌词**：支持 LRCLIB、实验性的 QQ 音乐网页来源及本地 LRC。可单独调整字体、字重、字号，以及当前句进入和上一句退出的动画。
- **下一首预告**：可导入本地 M3U/M3U8、JSON 歌单，或读取 QQ 音乐公开歌单；只在歌曲接近结束时显示预计下一首。
- **指定播放程序**：自动跟随当前媒体程序，也可在设置中选定一个程序，避免混入其他播放器的信息。
- **系统性能监视器**：按需显示所选游戏或程序的 FPS，以及整机 CPU、GPU 和物理内存。它与频谱共用玻璃风格，开启时从右向左推入，频谱收至左半；关闭后停止采样。

主题、按钮形状、MD3 进度样式、字体和多数动画都可以在分板块的设置中调整。不可用的选项会按条件隐藏，系统的“减少动态效果”设置也会被尊重。

## 🚀 下载与使用

Windows 10 2004（Build 19041）或更新的 x64 系统，以及 **.NET 8 Runtime x64**。程序不会把 .NET 一起打进安装包；如果缺少运行环境，启动时会询问是否通过微软官方地址在线安装。Windows 11 同样适用。

- **安装版**：运行 `MD3MusicWidget-Setup-<版本>.exe`，按向导安装。
- **免安装版**：完整解压 `MD3MusicWidget-Portable-<版本>.zip`，阅读其中的 `使用说明.txt`，再运行 `music_widget_flutter.exe`。不要只取出 EXE；`data/`、`runtime/`、`MusicFetcher.exe` 和 DLL 必须保持原有相对位置。
- **鼠标穿透恢复**：开启鼠标穿透后，点击托盘图标即可恢复交互；重启时也会恢复为可点击状态。

若播放器没有出现在 Windows 系统媒体控制中，本组件通常也无法获取其歌曲信息。频谱还取决于音频设备是否支持 Windows 回环采集；独占输出、受保护内容或部分虚拟声卡可能使其不可用。

## 🧩 工作原理

```text
播放器 → Windows 媒体会话 ─┐
                           ├→ MusicFetcher (.NET 8) → 本机回环连接 → Flutter/MD3 界面
音频输出 → WASAPI 回环 ────┘
公开歌单 / 在线歌词 ───────────────────────────────→ 可选 Provider
Windows 系统计数 / PresentMon ETW ────────────────→ 可选性能监视器
```

**MusicFetcher** 从 Windows 系统媒体会话读取标题、歌手、封面、状态和时间线，并按需采集音频频谱；Flutter 负责布局、动画、主题和绘制。两者通过 `127.0.0.1` 上的本机连接交换数据。关闭频谱时会停止相应采集，普通歌曲更新不会反复重建背景。

音乐平台 Provider 不是 QQ 音乐等平台的账号登录 SDK。公开歌单预告按歌名、歌手和列表顺序**推算**，不等于播放器的实际队列；私有歌单、随机播放、单曲循环、临时插播或匹配不唯一时，预告可能不可用或被隐藏。本地歌单可以避开公开歌单限制。

在“主题与外观 → 性能与诊断”中打开监视器，并选择帧率采集程序。选择会被保存，程序重启后按可执行文件名重新匹配。FPS 来自随程序附带的 PresentMon，通过 Windows ETW 读取所选进程提交画面的时间戳，不再使用桌面合成帧数；它不是显示器刷新率，也不保证等于实际显示帧率或插帧后的帧率。

CPU 来自 `GetSystemTimes`，物理内存来自 `GlobalMemoryStatusEx`，GPU 来自 Windows GPU Engine 性能计数器，取整机最繁忙的 GPU 引擎。原生后台线程负责采集，界面约每 0.5 秒更新一次；关闭监视器后停止采集并退出 PresentMon。无法取得的读数显示“—”，不会编造数字。若 Windows 拒绝 ETW 权限，设置中会提供需要你确认 UAC 的管理员重启按钮，不会静默提权。[采集方式与实测开销](docs/performance_monitor.md)

## 🔐 隐私与边界

歌曲信息、封面与音频采样默认只在本机处理，本机通信不向局域网开放。选择**在线歌词**时，歌名、歌手及可用时长可能发送给所选歌词服务；选择**QQ 音乐公开歌单**时，会请求该公开链接的数据。程序不会要求 QQ 音乐账号 Cookie，也不能绕过私有歌单权限。在线安装 .NET 需要访问微软下载地址。

第三方歌词和歌单接口可能变化；来源图标仅用于识别服务，不表示合作或官方授权。

## 🛠️ 从源码构建

需要 Flutter Windows 开发环境、Visual Studio 的 C++ 桌面开发组件以及 .NET 8 SDK。先构建 `MusicFetcher/` 中的辅助程序，再运行 `flutter pub get` 和 `flutter build windows --release`。GitHub 源码包只保留程序源码、必要资源和文档，不包含 Inno Setup、PowerShell 发布脚本及测试目录。

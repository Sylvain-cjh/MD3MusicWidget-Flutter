# 🎵 MD3 Music Widget

<p align="center"><img src="assets/logo.png" width="160" alt="MD3 Music Widget 图标"></p>

把正在播放的音乐，变成桌面或直播画面里的一张小卡片。

MD3 Music Widget 是一款 Windows 音乐展示组件，采用 Material 3 风格，集中显示歌曲、封面、播放进度、歌词与真实音频频谱。可以保留播放按钮，也可以隐藏控件，只展示音乐。

**当前版本：0.12.6** · [本次更新](CHANGELOG.md)

## ✨ 功能与外观

- **正在播放**：显示歌名、歌手、封面与进度；支持上一首、播放／暂停和下一首，也能一键隐藏三个控制按钮。
- **横竖布局**：在设置中切换横版或竖版，选择 82%、100%、122% 三档尺寸，或使用锁定宽高比的自由缩放。竖版不显示右侧附加封面。
- **随封面变化的主题**：动态取色、流光背景、左右光效、毛玻璃和 3D 悬浮封面；深色模式下关闭流光后可启用 OLED 模式。
- **右侧渐变封面**：横版附加封面自适应铺满；压暗程度、渐隐长度和柔化程度可分别调节、实时预览与重置。
- **真实音乐频谱**：支持均衡柱状、镜像频谱和平滑波形。暂停或没有歌曲时保留面板，不用随机波动代替真实音频。
- **歌词展示**：支持 LRCLIB、QQ 音乐实验来源及本地 LRC；实际来源使用对应图标。歌词可跟随主题字体，也可独立设置字体、字重和字号。
- **下一首预告**：支持本地 M3U／M3U8、JSON 歌单及 QQ 音乐公开歌单。在设定的临近结束时间内出现，不常驻、不保留空白占位。
- **指定采集程序**：自动跟随系统当前播放器，或在设置中选择一个媒体程序。
- **性能监视器**：可选显示指定游戏／程序的 FPS，以及整机 CPU、GPU 和内存；与频谱共用玻璃卡片，开关时联动展开与收回。

歌名、歌手与歌词都支持多种切换动画，进入和退出可以联动或分别设置。按钮形状、进度条样式、导航形状和字体也能自行调整。设置分为窗口、外观、播放、歌词、字体五个板块，不可用的选项按条件隐藏。

## 🚀 开始使用

### 系统要求

Windows 10 2004（Build 19041）及更新版本的 **x64 系统**，包括 Windows 11；音乐采集程序需要 **.NET 8 Runtime x64**。

安装包不内置 .NET。首次启动时，如果缺少运行环境，程序会询问是否通过微软官方地址在线安装。

### 安装版与免安装版

1. 安装版运行 `MD3MusicWidget-Setup-0.12.6.exe`，按向导完成安装。
2. 免安装版完整解压 `MD3MusicWidget-Portable-0.12.6.zip`，阅读包内的 `使用说明.txt`，再运行 `music_widget_flutter.exe`。
3. 打开音乐播放器并播放歌曲；右键进入设置，调整布局、歌词、频谱和采集来源。

不要只复制主程序 EXE。`data/`、`images/`、`runtime/`、`MusicFetcher.exe` 和 DLL 需要保持原有相对位置。开启鼠标穿透后，点击托盘图标可恢复交互；退出程序使用托盘菜单。

当前发行文件使用自签名证书，其他电脑不会自动信任该证书，Windows 仍可能显示发布者或安全提示。发布文件附有 SHA256 校验清单。

## 🧩 工作原理

应用由 Flutter 界面、.NET 音乐采集程序和 Windows 原生监控模块组成。

- **歌曲信息**：MusicFetcher 从 Windows 系统媒体会话读取标题、歌手、封面、播放状态和时间线，经 `127.0.0.1` 本机连接交给 Flutter。播放器没有提供系统媒体会话时，组件通常无法读取它。
- **音频频谱**：使用 Windows WASAPI 音频回环采集信号，再生成频谱数据。关闭频谱会停止对应采集；播放设备、系统版本和输出方式会影响可用性。
- **视觉与缓存**：Flutter 负责主题、布局、动画和绘制。封面使用容量受控的复用池，并在内存压力下清理；缓存静默工作，不显示命中提示。
- **歌词与歌单**：通过独立 Provider 查询在线歌词、读取本地歌词或歌单。下一首预告按曲目信息和列表顺序推算，并非直接读取播放器的实际播放队列。

性能监视器使用以下来源：

| 显示内容 | 数据来源与含义 |
| --- | --- |
| FPS | PresentMon 读取 Windows ETW 图形事件，统计所选进程主要交换链提交画面的频率 |
| CPU | `GetSystemTimes`，整机 CPU 使用率 |
| GPU | Windows GPU Engine 性能计数器，整机最繁忙 GPU 引擎的使用率 |
| 内存 | `GlobalMemoryStatusEx`，整机物理内存使用情况；竖版只显示已用量 |

监控在后台线程采集，界面约每 0.5 秒更新；关闭监视器后停止采集并退出辅助进程。没有可信读数时显示“—”。FPS 不是桌面帧率或显示器刷新率，也不保证等于实际显示帧率、插帧后的帧率。若 ETW 权限不足，可在设置中手动授权管理员重启，不会静默提权。

[性能采集方式与测试说明](docs/performance_monitor.md)

## 使用边界与隐私

- QQ 音乐网页歌词和公开歌单属于实验性接入，第三方接口变化可能导致不可用；服务图标不代表官方合作。
- 私有歌单不能仅凭分享链接读取。本程序不要求 QQ 音乐账号 Cookie，也不绕过平台权限；可改用本地歌单。
- 下一首预告不是实际队列；随机播放、单曲循环、临时插播或曲目匹配不唯一时，可能无法可靠预测。
- 独占音频输出、受保护内容或部分虚拟声卡可能影响频谱；目标程序未持续呈现画面、最小化或呈现路径不受支持时，FPS 可能没有数据。
- 歌曲和音频采样主要在本机处理。本机通信不向局域网开放；启用在线歌词时，会向对应服务发送查询所需的歌曲信息。读取公开歌单和在线安装 .NET 也需要联网。

## 🛠️ 源码与自定义

源码包包含程序源码、必要资源、README 和 CHANGELOG，不包含 PowerShell 发布脚本、Inno Setup 文件、测试目录或未采用的图标草案。README 介绍产品，CHANGELOG 只记录当前版本的更新。

修改设置文案时，名称和选项文字位于 `lib/ui/widgets/settings_labels.dart`，说明小字位于 `lib/ui/widgets/settings_descriptions.dart`。

构建需要 Flutter Windows 开发环境、Visual Studio C++ 桌面开发组件及 .NET 8 SDK。先将 `MusicFetcher/MusicFetcher.csproj` 发布为面向 `win-x64` 的 framework-dependent 单文件程序，把生成的 `MusicFetcher.exe` 放在项目根目录，再执行 `flutter pub get` 和 `flutter build windows --release`。

MusicFetcher 没有源码更新时可复用已有构建，不需要随每次界面更新重新编译。

# 🎵 MD3 Music Widget

<p align="center"><img src="assets/logo.png" width="160" alt="MD3 Music Widget 图标"></p>

把正在播放的音乐，变成桌面或直播画面里的一张小卡片。

MD3 Music Widget 是一款 Windows 音乐展示组件，采用 Material 3 风格，集中显示歌曲、封面、播放进度、歌词与真实音频频谱。可以保留播放按钮，也可以隐藏控件，只展示音乐。

**当前版本：1.0.0** · [本次更新](CHANGELOG.md)

本次发行分别提供有分层模型版、无分层模型版和独立分层模型包；MusicFetcher 有更新时才增加独立更新包，全部材料汇总到同一个版本文件夹。前两种都有安装版、免安装版和程序源码；独立模型包用于给无模型版补装分层功能。

## ✨ 功能与外观

- **正在播放**：显示歌名、歌手、封面与进度；可在进度条后显示已播放和总时长。歌名、歌手和播放时间根据背景明暗自动选择黑色或白色，保留纯净文字、不叠加灰色底框。支持上一首、播放／暂停和下一首，也能一键隐藏三个控制按钮。
- **横竖布局**：在设置中切换横版或竖版，背景模糊渐变，其余组件连续移动、缩放；中途反向也会从当前画面继续。选择 82%、100%、122% 三档尺寸，或使用锁定宽高比的自由缩放。100% 基准采用紧凑尺寸：横版宽 432、竖版宽 306 逻辑像素，高度随频谱、歌词和预告是否显示而变化；其他档位与新增面板同步缩放。竖版不显示右侧附加封面。
- **随封面变化的主题**：动态取色、流光背景、左右光效、毛玻璃和 3D 悬浮封面；白色区域占比较高的封面会跳过近白取色点，从其他区域寻找有效强调色，纯白或没有可靠颜色时采用稳定的中性配色。深色模式下关闭流光后可启用 OLED 模式。
- **右侧渐变封面**：横版附加封面自适应铺满；压暗程度、渐隐长度和柔化程度可实时预览与重置，X／Y 渐隐可以联动或分开调节。
- **真实音乐频谱**：支持均衡柱状、镜像频谱和平滑波形，粗细连续调节；柱数可随粗细自动变化，也可手动选择 1–128 根。少量柱不会简单拉伸铺满。暂停或没有歌曲时保留面板，不用随机波动代替真实音频。
- **歌词展示**：支持 LRCLIB、QQ 音乐与网易云音乐实验来源及本地 LRC；实际来源使用对应品牌图标。在线查询直连，不使用系统 HTTP 代理；暂时性失败会自动重试，成功获取的歌词可以保存在磁盘，重启后仍能使用。歌词可跟随主题字体，也可独立设置字体、字重和字号。可开启无歌词自动隐藏，收回可见外框但不反复改变系统窗口尺寸。
- **下一首预告**：支持本地 M3U／M3U8、JSON 歌单及 QQ 音乐、网易云音乐公开歌单。在设定的临近结束时间内出现，不常驻、不保留空白占位。网易云歌单也可按歌曲信息匹配其他系统播放器。
- **指定采集程序**：自动跟随系统当前播放器，或在设置中选择一个媒体程序。
- **性能监视器**：FPS、CPU、GPU、内存各自独立开关；FPS 对应所选游戏／程序，其他指标反映整机情况。显示一项或两项时带真实趋势波形，三项或四项时使用紧凑摘要；与频谱共用玻璃卡片，开关时联动展开与收回。

歌名、歌手与歌词都支持多种切换动画，进入和退出可以联动或分别设置；歌词包含胶片、翻页、放大和擦拭等预设。主封面有独立切歌样式：柔和滑移会根据上一首／下一首决定方向，旧封面按新封面的位置渐隐。播放按钮保留轻量分层 3D 反馈，按钮形状、进度条样式、导航形状和字体也能自行调整。设置分为窗口、外观、播放、歌词、字体五个板块，不可用的选项按条件隐藏。

设置中的数值滑块统一采用弹性手柄：按住时膨胀，拖动时按速度和方向拉伸，停住或松手后回弹。数值和点击区域始终跟手，不被动画延迟；系统开启减少动画时保留静态手柄和正常操作。顶部板块导航继续使用独立的液态滑块逻辑。

数值滑块采用 MD3 主题色、细圆角轨道和轻量状态层，不叠加玻璃或亚克力纹理。小尺寸手柄复用顶部板块滑块当前选择的轮廓，形变更克制，轨道在手柄下方留空；保留 48 逻辑像素的稳定交互区域。滚动设置的顶部和侧边留出安全间距，分组图标不会在列表起点被圆角边界切掉；滚动渐隐仍保留。

## 🚀 开始使用

### 系统要求

Windows 10 2004（Build 19041）及更新版本的 **x64 系统**，包括 Windows 11；音乐采集程序需要 **.NET 8 Runtime x64**。

安装包不内置 .NET。首次启动时，如果缺少运行环境，程序会询问是否通过微软官方地址在线安装。

### 安装版与免安装版

1. 先选择有分层模型版或无分层模型版，再运行套件内的 Setup 安装程序，按向导完成安装。
2. 免安装版完整解压所选版本的 Portable ZIP，阅读包内的 `使用说明.txt`，再运行 `music_widget_flutter.exe`。
3. 打开音乐播放器并播放歌曲；右键进入设置，调整布局、歌词、频谱和采集来源。

不要只复制主程序 EXE。`data/`、`images/`、`runtime/`、`MusicFetcher.exe` 和 DLL 需要保持原有相对位置。开启鼠标穿透后，点击托盘图标可恢复交互；退出程序使用托盘菜单。

发行文件沿用自签名证书，其他电脑不会自动信任该证书，Windows 仍可能显示发布者或安全提示。按新的发布约定，不再附带哈希校验清单。

## 🧩 工作原理

应用由 Flutter 界面、.NET 音乐采集程序和 Windows 原生监控模块组成。

- **歌曲信息**：MusicFetcher 从 Windows 系统媒体会话读取标题、歌手、封面、播放状态和时间线，经 `127.0.0.1` 本机连接交给 Flutter。播放器没有提供系统媒体会话时，组件通常无法读取它。
- **音频频谱**：使用 Windows WASAPI 音频回环采集信号，再生成频谱数据。关闭频谱会停止对应采集；播放设备、系统版本和输出方式会影响可用性。
- **视觉与缓存**：Flutter 负责主题、布局、动画和绘制。封面使用容量受控的内存复用池，并在内存压力下清理；歌词、背景源图及其平均色调还会写入独立的磁盘缓存。缓存静默工作，不显示命中提示。
- **封面分层（可选）**：有模型版通过 DirectML 在可用核显上生成主体蒙版、补全背景并绘制景深视差。模型推理不逐帧执行，也不以 CPU 推理回退；缺少兼容核显或无法可靠分离时保留普通封面。分层不是完整 3D 网格重建，不保证所有封面都能准确分离。
- **歌词与歌单**：通过独立 Provider 查询在线歌词、读取本地歌词或歌单。下一首预告按曲目信息和列表顺序推算，并非直接读取播放器的实际播放队列。

性能监视器使用以下来源：

| 显示内容 | 数据来源与含义 |
| --- | --- |
| FPS | PresentMon 读取 Windows ETW 图形事件，统计所选进程主要交换链提交画面的频率 |
| CPU | `GetSystemTimes`，整机 CPU 使用率 |
| GPU | Windows GPU Engine 性能计数器，整机最繁忙 GPU 引擎的使用率 |
| 内存 | `GlobalMemoryStatusEx`，整机物理内存使用情况；竖版只显示已用量 |

监控在后台线程采集，界面约每 0.5 秒更新；关闭指标会停止其对应采集，关闭监视器后停止全部采集并退出辅助进程。趋势波形最多保留最近 60 个真实采样点，缺失数据不补零、不制造随机波动。没有可信读数时显示“—”。FPS 不是桌面帧率或显示器刷新率，也不保证等于实际显示帧率、插帧后的帧率。若 ETW 权限不足，可在设置中手动授权管理员重启，不会静默提权。

### 缓存与查询重试

在 **设置 → 外观 → 缓存与存储** 中，通过滑块分别设置歌词和背景缓存的磁盘容量，**每档 1 MiB**，范围分别为 0–256 MiB、0–1024 MiB，默认分别为 **16 MiB** 和 **128 MiB**。滑动时实时显示容量，松手或短暂停止调节后保存并整理缓存，避免每次拖动都触发磁盘清理。超出容量时优先清理最近较少使用的内容；调到 0（“不保留磁盘缓存”）会清理对应磁盘缓存，但不移除当前正在显示的内容。

缓存位于 `%LOCALAPPDATA%\MD3MusicWidget\cache-v1`，不会因为正常退出或关机而消失。清理缓存按钮仅删除本程序保存的缓存，不会删除你自己的 LRC、歌单或其他文件。背景缓存保存的是封面源图和色调信息，并非最终的 GPU 模糊纹理；重启后仍需重新解码、绘制背景，缓存容量也不是运行内存上限。

在线歌词会先读取有效缓存；没有命中时再查询所选来源。暂时性网络错误或支持重试的未匹配结果最多尝试三次，两次间隔约为 0.5 秒和 1.5 秒。切歌会取消旧歌曲的重试，权限错误、限流和无效数据不会盲目重试。手动强制刷新会绕过持久歌词缓存。

文字反色使用封面低分辨率平均色调、当前主题和背景遮罩估算明暗，不进行持续的 GPU 像素回读。因此开销较小，但局部颜色反差极大的封面仍需在实际画面中检查可读性。

默认字体内置 MiSans VF，无需在电脑上另行安装。用户选择的自定义字体仍优先，歌词也能单独设置；字重滑块连续映射到该字体的真实可变轴，Windows UI 字体继续补足未覆盖字符。本应用使用 MiSans，许可见[小米官方 MiSans 协议](https://hyperos.mi.com/font/zh/download/)。

主要显示文字在布局或 DPI 变化后记录一次物理像素基线对齐偏移，后续重绘和移动保留这个偏移，不再因重绘次数切换位置。缩放使用 Flutter 原生文字绘制，不把整段文字预先转换成低分辨率位图再放大。这是字体与 DPI 清晰度优化，并非强制开启 RGB/ClearType 次像素抗锯齿；后者没有通过 Flutter `TextStyle` 提供应用级开关。

自由缩放会区分真实拖拽与窗口物理像素取整误差，忽略一物理像素以内的尺寸误差回写；临时零尺寸和过期布局回调不会改写选定比例。设置滑块的重置按钮预留固定空间，显示与隐藏时不会把后面的设置项挤动。

背景图片解码完成后才开始连续混合，快速切歌会继承当前画面。大范围模糊按封面、尺寸、模式和 DPI 缓存，过渡时复用结果；不靠降低采样尺寸或删除流光、渐隐效果来减少重复计算。媒体数据暂时缺失时保留上一张有效图片，持续缺失时先淡出再释放。

设置页的悬停高亮、导航、滚动区域和播放器采用分开的绘制边界；鼠标悬停只更新高亮层，不切换板块、不重播设置项进入动画，也不写入原生窗口尺寸。设置页的透明 Material 仅承接本区域的交互绘制，不增加遮罩底色。

## 使用边界与隐私

- QQ 音乐、网易云网页歌词及公开歌单属于实验性接入，第三方接口变化可能导致不可用；服务图标不代表官方合作。网易云歌词不读取登录凭据，找不到或匹配有歧义时回退到 LRCLIB，并显示实际来源。
- 私有歌单不能仅凭分享链接读取。本程序不要求 QQ 音乐账号 Cookie，也不绕过平台权限；可改用本地歌单。
- 下一首预告不是实际队列；随机播放、单曲循环、临时插播或曲目匹配不唯一时，可能无法可靠预测。
- 独占音频输出、受保护内容或部分虚拟声卡可能影响频谱；目标程序未持续呈现画面、最小化或呈现路径不受支持时，FPS 可能没有数据。
- 歌曲和音频采样主要在本机处理。本机通信不向局域网开放；启用在线歌词时，会向对应服务发送查询所需的歌曲信息。读取公开歌单和在线安装 .NET 也需要联网。

## 🛠️ 源码与自定义

源码包包含程序源码、必要资源、README 和 CHANGELOG，不包含 PowerShell 发布脚本、Inno Setup 文件、测试目录或未采用的图标草案。README 介绍产品，CHANGELOG 只记录当前版本的更新。

修改设置文案时，名称和选项文字位于 `lib/ui/widgets/settings_labels.dart`，说明小字位于 `lib/ui/widgets/settings_descriptions.dart`。

构建需要 Flutter Windows 开发环境、Visual Studio C++ 桌面开发组件及 .NET 8 SDK。先将 `MusicFetcher/MusicFetcher.csproj` 发布为面向 `win-x64` 的 framework-dependent 单文件程序，把生成的 `MusicFetcher.exe` 放在项目根目录，再执行 `flutter pub get` 和 `flutter build windows --release`。

MusicFetcher 没有源码更新时可复用已有构建，不需要随每次界面更新重新编译。
